# Required DK brand fonts

The existing About page references the following local brand font files from this directory:

| Required file | Font family / role |
|---|---|
| `Helvetica.ttf` | DK Helvetica Regular |
| `helvetica Light.ttf` | DK Helvetica Light |
| `Helvetica Bold.ttf` | DK Helvetica Bold |
| `Helvetica Oblique.ttf` | DK Helvetica Oblique |
| `helvetica Compressed.otf` | DK Helvetica Compressed |
| `century_normal.ttf` | DK Century Regular |
| `century_bold.ttf` | DK Century Bold |

These licensed font binaries were not present in the available page export, so no substitutes have been added. Place the approved brand files here using the exact filenames above to preserve the intended typography. The page includes standard font fallbacks and remains functional until the brand binaries are added.
