# DK Consulting — About Page

This repository contains the existing DK Consulting About page only.

## Included

- `index.html` — the complete About page, including inline styles, responsive behavior, scripts, and base64-embedded logo and portrait assets.
- `assets/fonts/README.md` — the exact approved DK brand font filenames the page expects.
- `.gitignore` — excludes local environment files, secrets, dependencies, and build artifacts.

## Run locally

Serve the directory with any static web server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Brand fonts

The source export expects approved DK font files in `assets/fonts/`. Those licensed binaries were not available in the current workspace, so they have not been replaced with substitutes. See `assets/fonts/README.md` for the required filenames.
